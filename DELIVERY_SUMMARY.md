🚀 HOW TO GET STARTED
═══════════════════════════════════════════════════════════════════════════════════

OPTION 1: Direct Opening (Fastest)
──────────────────────────────────
  1. Locate: e:\Social Engineering Simulator\index.html
  2. Action: Double-click the file
  3. Result: Website opens in your default browser
  4. Done! Click "Start Simulation"

OPTION 2: Using Python Server
──────────────────────────────
  1. Open terminal/command prompt
  2. Navigate to project folder
  3. Run: python -m http.server 8000
  4. Visit: http://localhost:8000
  5. Done! Website loads in browser

OPTION 3: VS Code Live Server
──────────────────────────────
  1. Open project folder in VS Code
  2. Right-click on index.html
  3. Select: "Open with Live Server"
  4. Browser opens automatically
  5. Done! Click "Start Simulation"
